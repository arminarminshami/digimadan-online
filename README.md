# دیجی‌معدن (DigiMadan) — نسخه‌ی کامل پلتفرم

این پروژه شامل کل کدی است که در طول توسعه‌ی پلتفرم ساخته شده: سایت اولیه + سیستم حراج، کیف‌پول، چت، اعلان، قیمت، مقالات/اخبار، پنل ادمین کامل و هرو سینمایی سه‌بعدی.

## نصب و اجرا

```
npm install
npm run dev
```

برای build نهایی:
```
npm run build
```

این پروژه از قبل به Cloudflare Pages (`digimadan.com`) و یک پروژه‌ی Supabase واقعی (`gdafmztscwtqtjzgnhvp`) وصل است. کافیست این فایل‌ها را در ریپازیتوری GitHub فعلی (`arminarminshami/digimadan`) جایگزین کنید و Push بزنید؛ Cloudflare خودش دیپلوی می‌کند.

## وضعیت دیتابیس

تمام جدول‌های لازم (حراج، کیف‌پول، چت، اعلان، قیمت، مقاله، تنظیمات پیامک/قیمت/هوش‌مصنوعی) از قبل **مستقیماً روی پروژه‌ی Supabase واقعی شما اجرا شده‌اند**. فایل `supabase/migration_001_platform_expansion.sql` فقط برای آرشیو/مرجع است؛ نیازی به اجرای دوباره‌ی آن نیست.

Edge Function `otp-auth` (ورود با کد پیامکی) نیز از قبل دیپلوی و فعال است.

## نقشه‌ی کلی صفحات

**عمومی:** `/` `/ads` `/ads/:id` `/submit-ad` `/login` `/dashboard` `/messages` `/prices` `/news` `/articles` `/articles/:slug` `/about` `/contact`

**ادمین (نیاز به ورود با حساب owner):** `/admin` `/admin/ads` `/admin/auctions` `/admin/content` `/admin/settings` `/admin/pages` `/admin/banners`

## سرویس‌هایی که آماده‌اند ولی منتظر کلید واقعی شما هستند

این‌ها همه از `/admin/settings` قابل تنظیم‌اند:

1. **پنل پیامک:** فعلاً کد تایید به‌جای پیامک، در جدول `sms_log` (قابل مشاهده در همان صفحه‌ی تنظیمات) ثبت می‌شود. وقتی provider واقعی (کاوه‌نگار/ملی‌پیامک/...) و کلید API را وارد کنید، باید کد ارسال واقعی هم در `supabase/functions/otp-auth/index.ts` تکمیل شود (ساختار آماده، فقط چند خط کامنت‌شده باید فعال شود).
2. **سرویس قیمت جهانی:** مثل metals-api.com یا metals.dev — بعد از وارد کردن کلید، باید یک Edge Function/Cron برای فراخوانی دوره‌ای آن ساخته شود (هنوز ساخته نشده — فقط ساختار جدول و رابط کاربری آماده است).
3. **هوش مصنوعی:** فقط معماری (مکالمه، پیام، تنظیمات) ساخته شده؛ اتصال واقعی به یک مدل زبانی هنوز انجام نشده.

## آنچه هنوز ساخته نشده

- PWA (manifest + service worker آفلاین)
- متادیتای سئو/OpenGraph پیشرفته

- چندزبانگی انگلیسی
